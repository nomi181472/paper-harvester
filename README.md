# Paper Harvester & Archive

Central repository and storage archive for all research papers and PDFs used across the interactive research labs at [lab-simul](https://github.com/nomi181472/lab-simul).

## Structure

Papers are organized by topic and corpus domain:

- `papers/`
  - `networking/`
  - `neuroevolution/`
  - `object_detection/`
  - `object_trackers/`
  - `pose_estimation/`
  - `transformers/`
  - `wifi_sensing/`
  - `knowledge_engineering/`
- `neuroevolution/`

## Usage with Lab Web Application

The web application and simulation engines reside in [nomi181472/lab-simul](https://github.com/nomi181472/lab-simul). To run the full application with all PDF previews locally, clone or link this paper directory into the `lab` project:

```bash
git clone https://github.com/nomi181472/paper-harvester.git
```
